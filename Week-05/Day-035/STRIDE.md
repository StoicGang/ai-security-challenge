
# STRIDE

| STRIDE Category            | What It Represents                                                          | Relevance to This Project                                                                                                                                                                                                                                  |
| -------------------------- | --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Spoofing**               | Impersonating a user or entity to gain unauthorized access.                 | **Not identified** in the current assessment because the application does not implement an authentication or identity-based access-control flow.                                                                                                           |
| **Tampering**              | Unauthorized modification of data or system state.                          | **Low / Not directly applicable** because the available tools have no write capability and the agent cannot modify files or external systems.                                                                                                              |
| **Repudiation**            | Performing an action without sufficient evidence to prove who performed it. | **Not identified** because auditability and user attribution are outside the current application's implemented scope.                                                                                                                                      |
| **Information Disclosure** | Exposing information to an entity that should not have access to it.        | **Potentially applicable** because prompt injection or unintended tool use could become an information-disclosure threat if sensitive information were reachable through an exposed capability. Current tool restrictions significantly limit this impact. |
| **Denial of Service**      | Making a system or resource unavailable or exhausting its resources.        | **Potentially applicable at a low level** because the application consumes LLM and tool resources, corresponding with the Day 024 LLM10 finding, but the current tools are lightweight and there are no recursive or expensive operations.                 |
| **Elevation of Privilege** | Gaining capabilities or permissions beyond those intended.                  | **Potentially applicable** because the Day 024 LLM06 finding identified agent tool access as an attack surface. However, least-privilege tool design limits the ability to escalate beyond the capabilities explicitly implemented.                        |
